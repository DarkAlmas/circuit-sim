# Схемотехник — симулятор схем с ESP32 / ESP8266 в браузере

Статическое веб-приложение без сборки (vanilla JS). Откройте `index.html` через любой HTTP-сервер (`python3 -m http.server`).
Worker не работает с `file://`.

## Файлы
| Файл | Что делает |
|---|---|
| `solver.js` | Решатель: метод узловых потенциалов (MNA) + Ньютон–Рафсон. Независим от UI. |
| `parts.js` | Библиотека деталей: выводы, отрисовка SVG, `stamp` (вклад в схему), `measure`, `check`. |
| `netlist.js` | Сборка схемы из проекта: объединение выводов проводами в узлы, земля, вызов `stamp`. |
| `transpile.js` | Упрощённый Arduino C → async JS. |
| `worker.js` | Выполняет скетч в Web Worker без сетевых API. |
| `app.js` | Интерфейс: холст, палитра, свойства, панель «Расчёт», консоль, проекты. |
| `examples.js` | Примеры проектов. |
| `tests/` | `node --test tests/` |

## API решателя (`solver.js`)
```js
const r = Solver.solve({ nodeCount, elements }, { guess, maxIter = 400, tol = 1e-7, maxStep = 0.15 });
// r = { ok, error, v: Float64Array (напряжения узлов, v[0] = 0), iter, currents: [...] }
```
Узел `0` — земля. Элементы:
| type | поля | `currents[i]` |
|---|---|---|
| `R` | `a, b, R` (Ом) | ток a→b |
| `V` | `p, n, V` идеальный источник | ток, отдаваемый из `+` во внешнюю цепь |
| `I` | `a, b, I` | ток a→b через источник |
| `D` | `a, b, Is, n` (Шокли) | ток анод→катод |
| `Q` | `c, b, e, Is, bf, br` (NPN, Эберс–Молл) | `{ic, ib, ie}` — токи, втекающие в выводы |

Сходимость: `gmin = 1e-12` от каждого узла к земле и параллельно p-n-переходам, экспонента с линейным продолжением
выше 40·Vt, демпфирование шага (изменение напряжения на переходе ≤ `maxStep` за итерацию), тёплый старт через `guess`.
Хелперы: `Solver.ledIs(Vf, n=2, Iref=10 мА)` — Is светодиода по Vf; `Solver.presets['1N4148' | '2N2222']`.

Чтобы добавить нелинейный элемент: допишите в `models` функцию, возвращающую токи, втекающие в выводы (`f`),
и якобиан `J[k][m] = ∂f_k/∂v_m`, и функцию выводов в `terms` — штамп сделается автоматически.

## Деталь (`parts.js`)
`{ name, group, props, pins:[{id,x,y,label}], draw(p, st) → SVG, stamp(p, ctx), measure(p, sol, ctx) → {U,I,P,pinI}, check(p, m, ctx) → {level:'warn'|'burn', msg} }`.
`ctx.n(p, pin)` — узел вывода, `ctx.node()` — новый внутренний узел, `ctx.add(el)` — индекс элемента, `ctx.gpio(n)` — состояние GPIO.

## Плата и скетч
GPIO в режиме OUTPUT — источник 3,3 В·скважность через 25 Ом; INPUT — высокоомный; INPUT_PULLUP — 45 кОм к 3,3 В. 3V3 — 3,3 В, VIN — 5 В (USB).
Поддерживается: `setup/loop`, свои функции, `#define`, типы int/float/long/bool/byte/String, массивы, `pinMode, digitalWrite, digitalRead,
analogWrite` (ШИМ как среднее напряжение), `analogRead` (12 бит у ESP32, 10 бит у ESP8266), `delay, millis, micros, map, constrain, random,
Serial.print/println`. Для NodeMCU есть `D0…D8, A0`. Скетч работает в Worker, `fetch/importScripts/XMLHttpRequest/WebSocket` удалены;
если 2 с нет ответа (бесконечный цикл без `delay`), Worker завершается.

## Ограничения v1
Только постоянный ток (DC, квазистатика по кадрам): нет конденсаторов, катушек, переходных процессов; ШИМ усредняется.
Транслятор — регулярные выражения, а не полноценный компилятор C (целочисленное деление, указатели, struct, классы не поддерживаются).
Orange Pi пока нет.
